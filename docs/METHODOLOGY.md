# Методика SERVICE 5D в коде (версия 5D-1.0)

Источник: `src/domain/methodology/v1.ts`. Любое изменение критериев, весов, формулировок или связей причин — это новая версия методики. Результаты прошлых диагностик остаются привязанными к своей версии (`Assessment.methodologyVersion`, `AIAnalysis.methodologyVersion`).

## Направления и критерии

5 направлений по 20% в SSI, 26 универсальных критериев (C1–C6, T1–T5, L1–L5, S1–S5, B1–B5) с весами 1–2. К ним добавляются индивидуальные критерии компании с весом 1–3. Для каждого критерия заданы:

- утверждения для оценки по каждому применимому источнику;
- влияние на бизнес, срочность и реализуемость (1–5);
- возможные первопричины (ссылки на другие критерии);
- последствия, рекомендуемое решение и чек-лист.

## Расчёт

- Оценка критерия **s** = среднее из средних по источникам (каждый источник весит одинаково, независимо от числа ответов).
- Направление: **D = 25 × Σ((s − 1) × w) / Σw**, диапазон 0–100.
- **SSI** = среднее пяти направлений, только если данных достаточно по всем пяти. Иначе SSI = `null` и выводится список ограничений.
- Направление оценивается, если:
  - покрытие весов критериев данными ≥ 60%;
  - есть данные ключевого источника: клиенты или тайный покупатель для CUSTOMER, сотрудники для TEAM и LEADERSHIP.
- Достоверность:
  - **высокая** — ≥ 2 источников, покрытие ≥ 90% и ключевой источник набрал норму ответов;
  - **средняя** — ≥ 2 источников и норма ответов набрана;
  - **низкая** — остальные случаи.
- Уровни: < 25 — критический, < 50 — низкий, < 75 — базовый, < 90 — хороший, ≥ 90 — высокий.
- Критический риск: критерий ≤ 1,8 или направление < 25.

## Бизнес-показатели как источник

Учитываются только фактические данные (`FACT`).

- **B1** по изменению выручки за 3 месяца (к прошлому году или к предыдущим 3 месяцам): ≥ +10% → 5; ≥ +3% → 4; ≥ −3% → 3; ≥ −10% → 2; иначе 1.
- **B2** по доле повторных продаж: ≥ 50% → 5; ≥ 35% → 4; ≥ 20% → 3; ≥ 10% → 2; иначе 1.

## Выводы анализа

- **Проблема** фиксируется, если выполнено одно из условий:
  - итоговая оценка критерия ≤ 3,0;
  - ключевой источник направления оценивает критерий ≤ 3,0 — высокая самооценка руководства не маскирует проблему;
  - расхождение руководство/«поле» ≥ 1,5 и оценка «поля» ≤ 3,0.
- **Статус вывода:**
  - *подтверждено* — низкие оценки у ≥ 2 источников, либо у одного надёжного источника плюс подтверждение в открытых ответах;
  - *частично подтверждено* — низкая оценка у одного источника;
  - *гипотеза* — вывод только по расхождению оценок или причина без данных.
- **Противоречие:** разница средних «собственник + руководитель» и «сотрудники + клиенты + тайный покупатель» ≥ 1,5.
- **Первопричина** проверяется данными критерия-причины:
  - ≤ 3,0 у двух источников (или у одного плюс тема в открытых ответах) → подтверждена;
  - ≤ 3,0 у одного источника → частично подтверждена;
  - нет данных → гипотеза;
  - > 3,0 → отбрасывается.
- **Темы открытых ответов** определяются лексиконом `TEXT_THEMES`. Цитаты анонимных источников показываются, только если респондентов ≥ K; контакты из цитат удаляются.

## Приоритизация

Приоритет = Σ (параметр × вес). Веса по умолчанию: серьёзность 0,30; влияние на бизнес 0,25; срочность 0,20; масштаб 0,10; системность 0,15. Пороги: P1 ≥ 3,8; P2 ≥ 3,2; P3 ≥ 2,6; ниже — P4. Реализуемость считается отдельно и на категорию не влияет. Веса и пороги настраиваются в «Настройки → Приоритизация».

## Оценка результата

Задача принята → «ожидает повторного замера». При завершении следующей диагностики критерий проблемы сравнивается «до/после» по эффективной оценке (минимум из итоговой и оценки ключевых источников):

- рост ≥ 0,3 → «улучшение подтверждено»; проблема переходит в статус «устранена», если новая оценка > 3,0;
- иначе → «эффект не подтверждён», проблема возвращается в работу.

## Параметры для калибровки на пилотах

Порог проблемы (3,0), порог противоречия (1,5), минимальное покрытие (60%), порог критичности (1,8), веса и пороги приоритета, порог эффекта (0,3), нормы ответов по источникам, пороги B1/B2, лексикон тем. Все они сосредоточены в `src/domain/*`.
