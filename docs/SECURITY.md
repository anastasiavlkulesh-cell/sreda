# Безопасность и персональные данные

| Требование ТЗ | Реализация |
| --- | --- |
| Безопасная авторизация | Auth.js v5; пароли argon2id (m=19 МиБ, t=2); не более 5 неудачных попыток за 15 минут на e-mail; выравнивание времени ответа; сессия 12 ч; `sessionVersion` для мгновенного отзыва |
| Проверка прав на сервере | `requireOrgContext` / `actionContext` + повторная проверка в каждом сервисе; интерфейс только скрывает недоступное |
| Изоляция компаний | `tenantDb(orgId)` принудительно добавляет `organizationId` во все запросы; запрет записи в чужую компанию; тесты изоляции |
| Шифрование чувствительных данных | AES-256-GCM (`DATA_ENCRYPTION_KEY`): контакты сотрудников, Telegram chat id, токены ссылок анкет; S3 — шифрование на стороне сервера |
| Хранение секретов | Только переменные окружения; `.env` вне git; секреты не попадают в клиентский код (серверные модули помечены `server-only`) |
| Аудит | `AuditLog`: вход, регистрация, компании, роли и права, приглашения, диагностика, анализ, план, задачи, файлы, отчёты, помощник, политика хранения |
| Резервное копирование | Сервис `backup` в docker-compose: ежедневный `pg_dump`, хранение 14 дней. В продакшене — управляемые бэкапы облака + PITR |
| Доступ к файлам | Только через `/api/files/{id}` с проверкой видимости записи; ключи хранилища не раскрываются; `no-store` |
| Защита ПДн (152-ФЗ) | Согласие при регистрации; минимизация (анонимные анкеты не собирают имя, e-mail, точное время); хранение в РФ — выбор облака при развёртывании |
| Настройки согласий | «Настройки → Данные и согласия»: внешний AI, отраслевая аналитика, обучение моделей (по умолчанию выключено); минимальный размер группы; срок хранения |
| Политика хранения и удаления | `/api/cron/retention`: ответы анкет старше срока компании; попытки входа — 30 дней; уведомления — 12 месяцев. Архивирование сотрудника стирает его контакт |
| AI не смешивает компании | Анализ строится только по `ctx.db` своей компании; во внешний AI уходят обезличенные агрегаты одной компании |
| Анонимность | Анонимные ответы не связаны ни с пользователем, ни с одноразовой ссылкой; время округлено до суток; агрегаты при n ≥ K; защита от вычитания; комментарии без контактов и в перемешанном порядке; индивидуальные ответы не видит никто, включая собственника |
| Эксперт платформы | Только по приглашению, доступ ≤ 90 дней с автоматическим отключением; ограничение модулями; никогда не получает права управления компанией, пользователями и утверждения |

HTTP-заголовки: `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `Permissions-Policy`. Заголовок `X-Powered-By` отключён.

Рекомендации перед продакшеном:

- Content-Security-Policy с nonce;
- PostgreSQL RLS;
- WAF и ограничение частоты на публичных анкетах по IP;
- внешний аудит безопасности;
- оформление обработки ПДн (уведомление Роскомнадзора, договоры поручения обработки с компаниями-клиентами).
