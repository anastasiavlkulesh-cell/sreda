# СРЕДА — интеллектуальная система управления качеством бизнеса

> «Сервис начинается с отношения. Результат создаётся системой».

СРЕДА помогает собственнику диагностировать бизнес по методике **SERVICE 5D**, найти первопричины проблем, сформировать и утвердить план улучшений и проверить реальный результат повторным замером.

MVP: мультитенантная SaaS-платформа на Next.js 16, PostgreSQL и Prisma 7.

## Быстрый старт (локально)

Требования: Node.js 22+ и PostgreSQL 16+.

```bash
npm ci
cp .env.example .env            # заполните AUTH_SECRET и DATA_ENCRYPTION_KEY (openssl rand -base64 32)
npx prisma generate
npx prisma migrate deploy       # применить миграции
npm run db:seed                 # методика, каталог прав, демо-компания и учётные записи ролей
npm run dev                     # http://localhost:3000
```

Демо-вход собственника: `demo@sreda.local` / `DemoSreda2026`.
Учётные записи для проверки прав (пароль тот же): `network-manager@`, `location-manager@`, `manager@`, `employee@`, `platform-expert@sreda.local`.
Переопределить пароль можно переменными `SEED_DEMO_EMAIL` и `SEED_DEMO_PASSWORD`. В продакшене seed с демо-учётными записями не запускайте.

## Запуск в Docker

```bash
cp .env.example .env   # заполните секреты
docker compose up -d --build
docker compose exec app npm run db:seed   # по желанию — демо-данные
```

В составе: приложение, PostgreSQL 16, MinIO (S3), Mailpit (просмотр писем: http://localhost:8025) и ежедневная резервная копия БД (хранится 14 дней).

> Docker-конфигурация написана, но в среде разработки MVP Docker-демон был недоступен, поэтому `docker compose up` не прогонялся. Проверьте сборку образа при первом развёртывании.

## Тесты

```bash
npm run typecheck
npm test                  # модульные и интеграционные тесты (нужен PostgreSQL; БД sreda_test создаётся автоматически)
npm run test:e2e          # E2E (нужно запущенное приложение и выполненный seed)
```

Состояние на момент сдачи MVP: **91 модульный и интеграционный тест, 13 E2E-сценариев (десктоп и смартфон) — все проходят**; `tsc` и `next build` — без ошибок.

Переменные окружения тестов: `TEST_DATABASE_URL` (по умолчанию `postgresql://sreda:sreda@localhost:5432/sreda_test`), `E2E_BASE_URL`, `PW_CHROME_PATH` (путь к системному Chrome, если браузеры Playwright не установлены).

## Миграции

Штатно используются `npx prisma migrate dev` и `npx prisma migrate deploy`.

Для сред без доступа к `binaries.prisma.sh` есть офлайн-инструмент на официальном WASM-движке Prisma той же сборки:

```bash
npm run db:offline:create <name>   # создать миграцию из изменений schema.prisma
npm run db:offline:deploy          # применить
npm run db:offline:generate        # сгенерировать клиент без загрузки движков
```

Он создаёт миграции в стандартном формате `prisma/migrations`, совместимом с `prisma migrate deploy`. Для тестов в такой среде задайте `PRISMA_OFFLINE=1`.

## Что реализовано, а что — следующие этапы

Реализовано (MVP, спринты 1–6):

- авторизация, компании, точки, подразделения, приглашения;
- RBAC на 6 ролей с настройкой прав;
- диагностика SERVICE 5D по 6 источникам с анкетами, ссылками и контролем полноты;
- расчёт SSI с достоверностью и ограничениями;
- AI-анализ: противоречия, первопричины, статусы выводов, P1–P4;
- план улучшений с утверждением собственником;
- задачи с доказательствами, AI-проверкой и оценкой результата повторным замером;
- команда и анонимные пульс-опросы;
- бизнес-показатели (факт, оценка и прогноз раздельно, импорт CSV);
- главная панель, PDF-отчёт, уведомления (в приложении, e-mail, Telegram);
- AI-помощник, журнал аудита, политика хранения, демо-компания.

Следующие этапы (в интерфейсе помечены «Скоро» или пояснением):

- модули «Обучение», «Стандарты и регламенты», «Клиентский опыт» (Customer Journey, отзывы, жалобы); модели данных уже заложены;
- отраслевые наборы критериев;
- интеграции с CRM и POS;
- оплата подписки;
- вход через Яндекс ID / VK ID;
- PostgreSQL Row-Level Security как третий уровень изоляции;
- проверка на реальном внешнем LLM: слой готов и протестирован на имитации API, но ключа в среде разработки не было.
